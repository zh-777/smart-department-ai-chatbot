# 🎓 Smart Department Information Assistant | AI-Powered Chatbot

An AI-powered web application designed to help students access university department information quickly and efficiently. The chatbot provides instant responses about faculty members, fee structures, academic information, and other department-related queries through an interactive and user-friendly interface.

---

## 🚀 Features

- 🤖 AI-powered department chatbot
- 👨‍🏫 Faculty information lookup
- 💰 Fee structure information
- 📚 Academic and departmental guidance
- 🔍 Fast and accurate search
- 🌐 Responsive web interface
- 📊 CSV-based data management
- ⚡ Lightweight and easy to deploy

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/zh-777/smart-department-information-assistant.git
```

### 2. Navigate to the project

```bash
cd smart-department-information-assistant
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open your browser

```
http://127.0.0.1:5000
```

## 💡 How It Works

1. The user enters a question through the chatbot interface.
2. The application processes the request.
3. Information is retrieved from the available datasets.
4. The chatbot returns relevant responses about:
   - Faculty members
   - Fee structure
   - Department information
   - Academic guidance
